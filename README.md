# Croncave

A private computer in the cloud that keeps working while you're away, used through simple apps in a browser.

This repository holds the locally runnable prototype: `./scripts/dev.sh` starts everything, and
[docs/local-guide.md](docs/local-guide.md) walks through every flow. Read [AGENTS.md](AGENTS.md) first if you're
working on it; decisions are in [docs/decisions.md](docs/decisions.md).
